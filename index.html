Object Detection

A Python and OpenCV object detection project with YOLOv8, SSD MobileNet, Haar Cascades, SORT-style tracking, CSV logging, Flask API, Streamlit dashboard, training scripts, Docker support, and tests.

View Repository Read Setup Guide

Run the Dashboard

cd object_detection
python3 -m streamlit run dashboard/app.py

Run Detection

python main.py --source webcam --backend yolo --track

Train Custom YOLOv8

python train/train.py --data train/dataset.yaml --epochs 50
